# Python Tkinter Login Form

## Project Description
This project is a simple desktop login application developed using Python and Tkinter. It allows users to enter a username and password and checks whether the login information is correct.

## Features
- Username and password input
- Password masking
- Login validation
- Successful login notification
- Failed login notification
- Customized background and GUI design
- Custom popup message
